## 参与 / Contributing

欢迎通过 Issues 提出建议。提交代码时请附运行方法，并使用虚构的示例数据；请勿上传密钥、个人信息或客户资料。

Suggestions are welcome through Issues. Code contributions should include setup instructions and synthetic example data. Do not upload credentials, personal information, or client material.
